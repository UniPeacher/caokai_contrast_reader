# 预装书籍目录

把想要「开箱即读」的 EPUB 文件放到这个目录（建议用英文文件名，避免 URL 编码问题），
并在 `src/preload.ts` 的 `PRELOAD_BOOKS` 列表里登记对应文件名。

应用首次启动时会自动把它们导入书架；已导入过的文件不会重复导入（用户删除后也不会复活）。

**注意：这个目录里的 `*.epub` 不进入 git 仓库**（.gitignore 已排除）。大多数受版权保护的书
不应该提交到公开仓库——部署到自己的服务器时，把这个目录里的文件手动复制到服务器同一位置
再构建即可（`docker compose up -d --build` 会一并打包）。
