# 内置草书字体目录

应用默认的草书字体放在这里（文件不入 git 仓库）：

| 文件名 | 对应字体 | 说明 |
|---|---|---|
| `caoshu-jf.ttf` | 草书 1.00（简入繁出） | **默认**。简体码位映射到繁体草书字形，简体书、繁体书都能显示 |
| `caoshu-yb.ttf` | 草书 1.00（原版） | 仅繁体字形，适合读繁体书 |
| `caoshu-sgt.ttf` | 方正孙过庭书谱草书（孙过庭书谱草书） | 繁体字形，孙过庭《书谱》风格 |
| `caoshu-zdf.ttf` | 方正字迹-周东芬草书（周东芬草书） | 简繁字形都覆盖，简体书、繁体书都能显示 |
| `caoshu-hczp.ttf` | 汉呈张平草书 | 简繁字形 |
| `caoshu-bzfh.ttf` | 标准草书符号（LiQuan） | 简繁字形，草书符号/部首集 |
| `caoshu-swm.ttf` | 汉仪孙万民草书 | 简繁字形 |
| `caoshu-sgc.ttf` | 孙过庭草书（测试版） | 简繁字形，测试版字集可能不全 |
| `caoshu-yrz.ttf` | 书体坊于右任标准草书 | 简繁字形 |

字体来源：喵闪字库（miao3.cn），标注「商用免费」但版权归原作者，授权信息以原作者最终说明为准——
因此本仓库**不提交字体文件**。部署到自己的服务器时，把这两个 ttf 手动放到服务器同一路径再构建即可
（Docker 构建会一并打包进镜像）。

文件名对应关系登记在 `src/preload.ts` 同级的 `App.tsx` 字体注册逻辑与 `src/styles.css` 中；
换用其他草书字体时改这三处 + 文件名即可。
